Online Movie Rental System

Movie Rental, User Reviews & Payment Gateway Platform

A structured full-stack web application designed for browsing film titles, streaming rentals, managing shopping carts, leaving verified reviews, and processing digital transactions. Engineered with an MVC architecture and strict Object-Oriented principles.

Project Overview

The Online Movie Rental & Review System was developed as an end-to-end digital cinema platform where film enthusiasts can explore an extensive catalog of movies, evaluate ratings, post detailed reviews, and rent titles securely. The project focused on building reliable business logic around rental duration tracking, digital inventory control, and transaction consistency.

A central engineering objective was establishing a rigorous Model-View-Controller (MVC) architectural separation. By implementing strict Object-Oriented Programming (OOP) patterns, data transfer objects, and repository layers, the application ensures high maintainability and testability across backend endpoints and client interfaces.

Key Capabilities

Movie Catalog & Categorization

Rich catalog featuring genres, release dates, director details, trailers, and rental fee tiers.

Rental Cart & Expiry Logic

Dynamic rental cart allowing users to configure multi-day viewing windows with automated rental duration tracking.

Ratings & User Reviews

Community feedback engine with 5-star scoring and verified customer commentary on watched titles.

Secure Authentication & Sessions

User registration, session protection, and personalized rental history tracking across logins.

Technical Challenges & Solutions

Concurrency & Cart State Synchronization

Managing rental sessions alongside simultaneous user checkouts required robust database transaction boundaries. Implementing transactional updates prevented rental race conditions and maintained ledger accuracy.

Modular MVC Architecture

Decoupled business rules from presentation layers by enforcing OOP encapsulation, dedicated controller routing, and structured database queries for reliable performance.
